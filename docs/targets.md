# Rule targets

GENERATED — do not edit. Regenerate with `bun run schema` (scripts/generate-schema.ts). The rows
come from the target vocabulary (`@jint/contract`), the resolution predicate
(`packages/sdk/src/core/rules/classify.ts`), and each grammar's own `queries.scm` census — a
rule resolves what this table says or the generator fails.

The two rule-target namespaces are FILE / CAPTURE (`docs/designs/grammar-loading.md`).
The table below covers the CAPTURE namespace's fixed targets; a grammar's own capture is
addressed through the qualified `{grammar}:{capture}` form - markdown's four: `markdown:section`, `markdown:paragraph`, `markdown:list_item`, `markdown:list`.
